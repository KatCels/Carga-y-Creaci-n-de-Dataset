
# AE2 - Manejo de archivos CSV, JSON y TXT

## Descripción
Actividad de programación orientada a objetos para importar,
modificar y guardar archivos CSV y JSON, y generar un resumen TXT.

## Archivos principales
- `manejador_csv.py`: importa, modifica y guarda datos CSV.
- `manejador_json.py`: importa, modifica y guarda datos JSON.
- `generador_resumen_txt.py`: genera el resumen de ejecución.
- `actividad_2.ipynb`: coordina y demuestra el proceso.

## Archivos de datos
- `test.csv`: archivo CSV original.
- `detailed_report.json`: archivo JSON original.
- `test_modificado.csv`: resultado CSV.
- `detailed_report_modificado.json`: resultado JSON.
- `resumen.txt`: resumen generado por código.

## Fuentes originales
- CSV: PEGAR_URL_REAL_DEL_CSV
- JSON: PEGAR_URL_REAL_DEL_JSON

## Requisitos
Python 3 y Jupyter Notebook.

## Ejecución
1. Abrir `actividad_2.ipynb` en Jupyter.
2. Verificar las URL de origen.
3. Ejecutar las celdas en orden.
4. Comprobar los archivos generados y el contenido de `resumen.txt`.
