
# Carga y Creación de Dataset

## Descripción

Proyecto desarrollado en Python para cargar un conjunto de datos
desde Hugging Face, convertirlo en un DataFrame de pandas,
aplicar una transformación y generar un resumen en formato TXT.

## Tecnologías utilizadas

- Python
- Pandas
- Hugging Face Datasets
- Jupyter Notebook
- Git y GitHub

## Estructura del proyecto

- `hf_dataset_loader.py`: carga el dataset.
- `dataset_summarizer.py`: genera el resumen del DataFrame.
- `actividad_1.ipynb`: coordina el proceso completo.
- `requirements.txt`: contiene las dependencias.
- `resumen_dataset.txt`: contiene el resumen generado.

## Instalación

Instalar las dependencias con:

```bash
python -m pip install -r requirements.txt
```

## Ejecución

1. Abrir `actividad_1.ipynb`.
2. Ejecutar las celdas en orden.
3. Revisar el DataFrame y la transformación.
4. Consultar el archivo `resumen_dataset.txt`.

La carga del dataset desde Hugging Face requiere conexión
a Internet.
